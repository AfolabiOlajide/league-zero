# 4 — Public landing page

## Outcome

Signed-out visitors can understand LeagueZero before creating an account.

## Acceptance criteria

1. `/` displays a branded, responsive landing page for signed-out visitors.
2. The supplied public logo, Outfit typography, and existing theme tokens are used.
3. Content explains finding rivals, logging offline games, opponent verification,
   and private official history without advertising future features.
4. Get started links to `/sign-up`; Sign in links to `/sign-in`.
5. Signed-in root visitors retain the `/home` or `/onboarding` profile gate.
6. Example records are explicitly illustrative; no private data is fetched for visitors.
7. Keyboard navigation, reduced motion, mobile layouts, lint, and build are checked.
